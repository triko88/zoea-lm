# ZOEA-LM

**Note: The project was initially built using `candle` framework. However, I use an AMD GPU (RX 6800M), which is not supported by `candle`. So I'm migrating it to `burn` framework.**

A GPT-like small language model made from scratch using rust with `burn` framework. 
The name came from zoea, the larval stage of crab 🦀
